# Archived preprocessing subset

This folder contains the archived scripts most directly relevant to the final four-stream pipeline. They are provided as provenance/reference code and may require the original FI directory structure plus third-party packages.

Included: DINOv2-face, WavLM/eGeMAPS acoustic processing, RoBERTa textual processing, and cache-addition helpers. Legacy DeBERTa-v3, wav2vec2, OpenGraphAU, FabNet, and `__pycache__` material are not included in the formal main-flow subset.
